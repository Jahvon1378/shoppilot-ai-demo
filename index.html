Authorized supplier integration plan
1. Choose a supplier that explicitly permits dropshipping/resale.
2. Get its official API or app credentials with permission.
3. Check price, stock, shipping and product identifiers from the supplier's API.
4. Recalculate margin whenever cost or stock changes.
5. Start with manual purchase approval; only enable automatic fulfillment after testing.

Build path: demo → real service

These are the next implementation milestones, not features already connected.

01 · Validate demand

Pick one supplier and product category. Confirm its terms allow your intended model and compare actual sold prices.

02 · Connect official data

Add a secure backend for API credentials. Never put supplier secrets or payment keys in public website code.

03 · Controlled orders

Use a real checkout, stock re-check, order logs, customer support and refund handling. Require adult oversight and approval.

For a 15-year-old founder: involve a parent/guardian before opening seller, payment-processing, supplier or business accounts, signing contracts, or handling customer money. Providers set their own age and representative rules. Keep this demo in test mode until those accounts and responsibilities are properly set up.
